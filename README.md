# AI Alarm Management Demo

Interactive demonstration of AI-powered alarm management capabilities for industrial operations.

## Features

- **Root Cause Analysis**: AI identifies the primary alarm that triggered cascading failures using first-out timestamp analysis
- **Predictive Maintenance**: Early detection of sensor degradation before failure occurs
- **Contextual Smart Shelving**: Intelligent alarm suppression with risk assessment and continuous monitoring
